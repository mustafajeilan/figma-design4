# Figma Design 4

A clean responsive landing page mockup built from a Figma-inspired design using pure HTML and CSS.

## Overview

This project contains a single-page layout with an image section and a content section. It demonstrates a modern typography-driven landing page design using the Roboto font and custom styling.

## Files

- `index.html` — main page structure and markup.
- `css/styles.css` — styling for layout, typography, spacing, and button design.
- `images/` — image assets used by the design.

## Features

- Two-column layout with image and content sections
- Full-height visual presentation using `min-height: 100vh`
- Responsive-friendly layout with fluid image sizing
- Simple call-to-action button and feature blocks

## Usage

1. Open `index.html` in a web browser.
2. Review the design and modify `css/styles.css` to customize typography, spacing, and colors.

## Notes

- The project uses Google Fonts for the `Roboto` font family.
- The design is static and does not require a build step or server.
